                                                 ChatBot AI App / New Age

ChatBot AI App is a modern AI-powered chatbot application developed using Kotlin and Jetpack Compose as part of an Android assignment for New Age.

The application integrates Google Gemini AI for real-time conversations and follows MVVM architecture with clean and scalable project structure.

Features:

 Real-time AI chat responses
 Modern chat interface
 Chat history persistence using Room Database
 App Open Ads integration
 Adaptive Banner Ads integration
 Typing indicator
 Smooth scrolling conversation
 Gemini AI API integration

Tech Stack:

 Kotlin
 Jetpack Compose
 MVVM Architecture
 Retrofit
 Room Database
 Google Gemini AI
 Google AdMob


This project was created to demonstrate modern Android app development practices including API integration, local data persistence, clean architecture, and AdMob monetization integration.
